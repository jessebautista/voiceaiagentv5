Agent workspace

Shape how the receptionist thinks: system prompt, tools, and voice welcome.

Agent prompt (Live Connect & Chat)

Choose which agent personality and capabilities to use. Demo = FAQ, booking, calculator. Supabase = same plus CRUD on news, piano applications, piano activations.

System prompt override

When unchecked, this overrides the base prompt file. Changes apply on the next voice or chat request.

Enabled tools

Uncheck to disable a tool. When all are unchecked, the agent uses all tools (default).

Welcome message

Override the phrase played when a call starts. Leave empty for time-based default (Good morning/afternoon/evening…).

Tips

Use the chat console to iterate on the system prompt, then test the same behavior in Live Connect. Tools like get_current_datetime and get_reference_info are most useful when the prompt explains when to call them.
