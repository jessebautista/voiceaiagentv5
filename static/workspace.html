Workspace

Edit the voice agent: system prompt, tools, and welcome message.

System prompt

When "Use file default" is unchecked, this overrides the prompt file. Changes apply on next voice or chat request.

Enabled tools

Uncheck to disable a tool. When all are unchecked, the agent uses all tools (default).

Welcome message

Override the phrase played when a call starts. Leave empty for time-based default (Good morning/afternoon/evening…).
